The rfgap.py file contains a new and improved, sparse implementation of RF-GAP, a method for generating random forest proximities. It currently supports two types, rfgap and oob. 

The ProximityMixin.py file contains an abstraction of the RFGAP class that was used to generate proximity measures for additional forest-like methods.

What I would like is a mixture of the two in a new file. The file should define a class should be an abstraction of the proximity generation, but should be based on the sparse methodology offered by the rfgap.py file. It should be well documented with clear expectations for input/output types. Ideally, the method should work with a large selection of random forest-like classes, such as RandomForestClassifier, RandomForestRegressor, ExtraTreesClassifier, ExtraTreesRegressor, RotationForestClassifier and RotationForestRegressor (these last two are from the aeon package). It should be left general enough that the user can use the ProximityMixin as decorator for these classes. It will be up to me to determine other potential classes that may work (e.g., some version of Oblique random forests, Isolation forests, or others).

The two papers relating to these works (the original RF-GAP proximities paper and one describing the sparse version) are attached.

Other ideas for improvement are also welcome.
